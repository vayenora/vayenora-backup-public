# vayenora-backup-public

Public release assets for **Vayenora Backup** (direct download channel).

- `appcast.xml` — [Sparkle 2](https://sparkle-project.org) update feed,
  served via GitHub Pages: <https://vayenora.github.io/vayenora-backup-public/appcast.xml>
- GitHub Releases — distributable DMG installers (no authentication required)

The application source lives in a private repository. This repository is
intentionally public because Sparkle enclosure URLs and release assets must
be reachable without authentication.

App Store customers receive updates through the App Store; this feed is only
for the direct (Developer ID) channel.
